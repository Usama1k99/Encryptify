Enigmatrix File Encryptor (.emx)
1024×1024 Block Matrix Cryptography & Hybrid RSA-4096 Key Encapsulation

Enigmatrix is a high-security encryption algorithm engineered specifically for large-scale data and arbitrary file protection. It operates on structured 1024×1024 byte matrices (1 MB per block), utilizing hash-based multi-stage key expansion, cryptographic permutations, modular arithmetic transformations, and PRNG-driven obfuscation to guarantee computational security.

1. Multi-Stage Key Expansion Mechanism

Key expansion generates robust subkeys derived from the user's password through a deterministic expansion process:

  • Raw Key Handling: Accepts user passwords (minimum 4 characters) and computes the Primary Hash (PH) over the entire key. PH is mixed iteratively with downstream subkeys to achieve maximal avalanche effect and bit diffusion.
  • PRNG Seed Generation: The Primary Hash is split into four 128-bit segments. Two distinct seeds are derived by XOR-folding overlapping segments:
    • Seed 1 = (PH1 ⊕ PH2) ⊕ PH3
    • Seed 2 = (PH2 ⊕ PH3) ⊕ PH4
  • Alternating Hash Expansion: For each 1 MB block round, PH and previously generated subkeys are concatenated. Expansion alternates between SHA-256 on even rounds and BLAKE2b on odd rounds in a feedback loop until a full 1024×1024 subkey matrix (1,048,576 bytes) is populated.

2. Multi-Stage Block Transformations

Once the round subkey matrix is generated, Enigmatrix applies multi-stage transformations to the 1MB data matrix in an unpredictable sequence governed by PRNG:

  • Bitwise XOR: Each 1MB plaintext block is XORed with the round subkey matrix of equal dimension.
  • Modular Arithmetic Diffusion: The subkey matrix is applied using modular addition and subtraction: C[i,j] = (P[i,j] ± K[i,j]) mod 256. In round 2, the subkey matrix is transposed to introduce cross-axis diffusion.
  • PRNG-Driven Permutations: A minimum of 512 row and column swaps are executed per 1MB block. Seed 2 determines whether row or column swaps occur first, the exact coordinate pairs swapped, and the deterministic permutation sequence.

3. Reversible Decryption Pipeline

Decryption precisely reverses each transformation in reverse PRNG order: inverting modular operations, reversing row/column swaps using stored permutation trajectories, and executing the final subkey XOR restoration to reconstruct the original data byte-for-byte.

4. Hybrid RSA-4096 Key Encapsulation

Enigmatrix supports optional RSA envelope encryption. The symmetric file key can be sealed with a recipient's 2048-bit or 4096-bit RSA public key (RSA-OAEP) and stored in the .emx file header, allowing secure distribution without sharing the master password.

Image Encryption Suite
Steganos (LSB Steganography), PicIt (Text-to-Image), and Image XOR Scrambler

The Image Encryption Suite contains three distinct image-based security algorithms, designed for steganographic concealment, visual text synthesis, and bitwise pixel obfuscation:

1. Steganos - LSB Steganography (Open by Default)

Steganos conceals arbitrary secret text messages into the least-significant bits (LSB) of 24-bit RGB carrier images, rendering the hidden data completely imperceptible to human vision and statistical histogram inspection.

The engine groups pixels into 3-pixel tuples (9 color channels per character): the first 8 channels carry the 8-bit character codepoint by adjusting color value parity (even for 0, odd for 1), while the 9th channel stores an end-of-payload stop delimiter flag.

Coordinate traversal orientation (horizontal row-major vs. vertical column-major) is pseudo-randomly decided and stored in the header pixel (0,0). Steganos supports carrier key auto-embedding or password-protected mode, as well as integrated pre-encryption of the embedded payload using Vigenere, Vigenere+, PRNG Scramble, or Bitwise XOR.

2. PicIt - Text-to-Image Converter

PicIt synthesizes textual data directly into a standalone square PNG image canvas, reversing the traditional paradigm by turning text into pixel geometry.

The algorithm computes the minimum required canvas dimension D = ⌈√N⌉, mapping 3 characters per RGB pixel. Specialized corner pixels serve as an embedded hardware map storing payload byte length, coordinate pointers, and encryption strictness flags (encstrict).

The synthesized canvas then undergoes password-seeded spatial pixel coordinate shuffling. The resulting output appears as pure random noise and can only be de-scrambled and read back into text by the PicIt engine with the matching password.

3. Image XOR Scrambler / Unscrambler

Image XOR Scrambler locks and unlocks existing photographs and graphical assets using bitwise keystreams and spatial coordinate permutations.

The engine flattens 3D RGB arrays into contiguous 1D byte vectors and derives a repeating modular keystream matching the image's byte dimension from the password hash. Bitwise XOR operations (P ⊕ K = C) modify pixel color values, followed by a Fisher-Yates coordinate shuffle seeded by the key's PRNG state.

Decryption restores pixel positions via the inverse permutation trajectory and reapplies the identical XOR keystream, restoring the photograph with 100% losslessness.

Text Cryptography Suite
Bitwise XOR, PRNG Scramble, Vigenere / Vigenere+, and 8-bit Binary Ciphers

The Text Cryptography Suite provides fast, in-memory cryptographic primitives for strings, documents, and messages:

1. Bitwise XOR (Open by Default)

Computes byte-by-byte bitwise XOR between input plaintext character codepoints and a repeating keystream derived from the user's password.
Because XOR is an involutory mathematical operation (A ⊕ K ⊕ K = A), encryption and decryption are perfectly symmetrical while ensuring high-speed processing without ciphertext expansion.
Keystreams are derived dynamically to span the complete message length with modular wrapping.

2. PRNG Scramble

Extracts a deterministic pseudo-random seed from the cryptographic hash of the user's key.
Applies a key-seeded Fisher-Yates array permutation to the string's character indices, thoroughly scrambling character positions while preserving the exact character set.
Inversion reconstructs the original indices via recorded swap trajectories, providing robust spatial obfuscation.

3. Vigenere & Vigenere+

Classical Vigenere executes a polyalphabetic Caesar substitution where each character is shifted forward along the character space according to the matching key byte (C[i] = (P[i] + K[i mod m]) mod N).
The enhanced Vigenere+ mode injects a pre-shift PRNG coordinate scramble, destroying linguistic frequency analysis patterns before cyclic shifting.
Decryption reverses the cyclic shift and unscrambles character positions back into readable plaintext.

4. 8-bit Binary

Translates each UTF-8 plaintext character into its fundamental 8-bit binary representation (00000000 to 11111111) separated by spaces.
Serves as a transparent diagnostic and encoding utility requiring no secret key, allowing direct inspection and manipulation of raw computer bit patterns.
Decryption parses 8-bit byte clusters and reconstructs the original ASCII/UTF-8 character stream.
